wabridge

WhatsApp for your AI assistant. It lets your assistant read your WhatsApp messages and draft replies for you. It only reads and drafts — it never sends anything on its own.

A. Easiest — let your AI assistant do it

Copy this message and paste it to your AI assistant:

Please install wabridge for me on this computer. Fetch and run the installer:

curl -fsSL https://gist.githubusercontent.com/valstoneengineering/7dadd04022357514f2b80ec98d6fe798/raw/install.sh | sh

(if curl is missing, use: wget -qO- https://gist.githubusercontent.com/valstoneengineering/7dadd04022357514f2b80ec98d6fe798/raw/install.sh | sh)

Then run `wabridge setup` and follow what it says. Register the MCP server named "whatsapp" with the command `wabridge mcp`. When it's time to link WhatsApp, ask me for my WhatsApp number and show me the 8-character pairing code (or the QR code) so I can link it on my phone under WhatsApp → Settings → Linked devices → Link a device. Never send WhatsApp messages without my explicit OK.

B. Or do it yourself in a terminal

Open a terminal and paste this one line:

curl -fsSL https://gist.githubusercontent.com/valstoneengineering/7dadd04022357514f2b80ec98d6fe798/raw/install.sh | sh

Then run wabridge setup and follow the steps.

Needs a Debian or Ubuntu computer (64-bit Intel/AMD, "amd64") where you can use sudo.

Requirements & caveats: Debian/Ubuntu amd64 with sudo and internet access; a phone with WhatsApp to link it (it appears as a linked device you can remove at any time); the computer should stay on for messages to keep arriving. Read + draft only — nothing is sent without you.
